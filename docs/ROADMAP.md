# Development Roadmap

## Phase 1 — Voice + AI foundation
Establish the basic reasoning loop, text/voice input parsing, and base LLM integration.

## Phase 2 — Controlled macOS tools
Implement foundational system control capabilities (file management, system queries) with strict permissions.

## Phase 3 — Gmail integration
Develop OAuth-based read, summarize, and draft capabilities for Gmail.

## Phase 4 — Calendar + Tasks
Integrate with calendar APIs for scheduling and task list management.

## Phase 5 — Persistent Memory
Implement a local vector database for long-term recall and contextual awareness across sessions.

## Phase 6 — Web Research
Provide autonomous web search, scraping, and synthesis capabilities.

## Phase 7 — Workflow Automation
Enable the creation and execution of repetitive, multi-step macros and system tasks.

## Phase 8 — Notifications
Create a proactive notification system for schedule alerts, incoming priority emails, and task completion.

## Phase 9 — iPhone Companion
Develop an iOS client app for remote access and voice interaction on the go.

## Phase 10 — Security Hardening
Audit code, encrypt state, refine OAuth flows, and implement robust prompt injection defenses.

## Phase 11 — Final UI/UX
Polish the desktop and mobile interfaces with a focus on seamless interaction and visual feedback.

## Phase 12 — End-to-End Acceptance Testing
Comprehensive validation of all systems working in tandem to ensure stability and reliability.
